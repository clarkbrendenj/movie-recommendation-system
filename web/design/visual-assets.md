# The Midnight Theater visual assets

The curtain was generated with the built-in image generation tool using the
user's first screenshot as the material reference. The other two screenshots
guided the live Art Deco and illuminated marquee lettering, not the curtain.

- Runtime curtain: `public/images/midnight-velvet-curtain.webp`
- Size: 2172 × 724, 82,752 bytes; WebP quality 88, unchanged composition/resolution.
- Original generated image: retained in the generation tool's output directory.
- Typography: self-hosted Limelight, SIL Open Font License in
  `public/fonts/Limelight-OFL.txt`. Bebas Neue remains available as a fallback.
- Wordmark: live SVG text with red/gold letter faces and a steady warm bulb
  pattern. The header and footer each use unique SVG pattern identifiers.
- Background treatment: no tiling or blur, a light shading layer, and a minimum
  rendered width of 1100px to keep folds broad on phones.

## Final curtain generation prompt

Use case: photorealistic-natural. Asset type: wide website header background texture, a close-up of red velvet theater curtains. The user's FIRST attached image is the curtain material/composition reference: saturated deep blood-red/crimson velvet, broad softly rounded vertical pleats, near-black creases, very soft grazing highlights and visible fine velvet nap. The second and third reference images are typography references ONLY and must not appear in this curtain background. Generate an ORIGINAL photorealistic seamless-looking wide swath of closed crimson velvet stage curtains, front facing, spanning edge to edge. Landscape 3:1 composition, 1536 by 512 if supported. Broad irregular natural hanging folds about 8-12 across the whole image, organic slight bends, rich velvety cloth, deep inky maroon shadows, muted ruby highlights, soft directional stage lighting. Match the first reference's deep red hue and tactile velvet closely. No objects, no stage, no curtain tiebacks, no valance, no fringe, no openings, no black side bars, no horizontal seams, no logos, no writing or letters, no borders. This will be cropped as a website masthead behind a theater wordmark, so preserve visible red fabric and natural fold contrast across the entire wide frame. Avoid flat repetitive thin pinstripes, shiny satin, magenta/purple, orange, excessive glow, or a uniformly black image.
